# 10 Checkpoints for AI Projects (V1)

> The biggest risk in AI isn't moving too slowly.
> It's moving fast in the wrong direction.

AI projects fail because of architecture, not models.
These are the checkpoints I use to evaluate an AI system.
Versioned on purpose — this is V1, and it will evolve.

## Direction — think first
1. Outcome first
2. Separate inputs, outputs, and outcomes
3. Make the world model falsifiable

## Build — then act
4. Delete before you automate
5. Architecture over model
6. Solve a real problem, not fake work

## Calibrate — keep tuning
7. Keep people close to real feedback (FDE)
8. Re-solve for the optimum when costs shift
9. Use temporal versioning

## Foundation — runs through all
10. AI is a helper, not an alibi
